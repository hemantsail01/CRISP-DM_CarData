# CRISP-DM_CarData
his project applied the CRISP-DM framework to analyze the factors influencing used-car prices. The analysis examined vehicle characteristics, including age, mileage, manufacturer, condition, fuel type, transmission, drive type, vehicle type, and geographic location.

Exploratory analysis was used to identify relationships between vehicle characteristics and price, while regression models were developed to estimate vehicle prices. Model performance was evaluated using MAE, RMSE, and R².

The results provide the dealership with a data-driven approach for inventory acquisition and pricing. Rather than relying solely on historical averages or subjective judgment, the dealership can use the identified pricing factors and predictive model to make more informed purchasing and pricing decisions.

Future work should incorporate additional information such as actual transaction prices, vehicle options, maintenance history, accident history, number of previous owners, and market demand. These additional variables could improve the accuracy of future pricing models and provide a more complete understanding of consumer preferences.
